# 本地部署准备与迁移

目标：在不注册云账号、不新增付费资源的条件下，准备可换目录启动的本地试用包。当前新增预算0元，后续云平台未选定。此部署包不代表小程序已经正式发布。

## 两种交付包

- `校院政策咨询Agent项目包.zip`：源码、原始政策副本、前端构建、验证记录和文档；不含模型、依赖和运行数据。
- `校院政策咨询Agent本地部署包.zip`：在上述文件基础上加入固定修订的Qwen2.5-0.5B-Instruct、BGE模型、93片段语义向量，以及相对路径的模型配置。解压后的应用目录为 `policy-agent-local`。不含Python解释器、虚拟环境、依赖安装包、微信AppSecret、学生历史、管理员登录码或本机数据库；新机器安装依赖仍需可用网络。

部署包只导入最初45份政策副本及其语义索引，不搬运本地政策草稿、历史发布和用户身份。以后要迁移真实运行数据，应使用项目的一致性备份与恢复流程，不能拿这个干净试用包当作数据库备份。

## Windows新目录或新机器

准备Windows与Python3.13，建议至少预留8GB内存与足够磁盘；实际模型响应及并发仍需测量。解压时保留包内的目录结构。

在解压后的 `policy-agent-local` 目录打开PowerShell：

```powershell
./scripts/Setup.ps1 -UseBundledModels
./scripts/Start.ps1
```

`Setup.ps1` 创建当前目录专用虚拟环境并安装锁定依赖，然后核对部署包及模型、向量的完整性。`-UseBundledModels` 不重新下载权重、不把已有语义索引改成字符基线；不要同时传入 `-DownloadModels`。在脚本禁止运行的机器上按本机管理规则处理，不自动更改系统执行策略。

默认网页地址为 `http://127.0.0.1:8000`。当前已有项目占用8000端口时，不重复启动新副本；可先在不同本机端口隔离验证，但微信构建的API默认仍指向8000，必须与实际本地后端匹配。原项目停启由其自己的Start/Stop脚本管理，不终止无关进程。

匿名咨询无需微信密钥。若在新目录使用真实微信登录，由本人在新环境的服务端配置AppSecret；不要把本机 `.env` 放进可分发部署包，也不要把AppSecret写入小程序。新副本没有管理账号，需要在该副本目录用 `app.admin_cli invite` 另行建立本地管理登录。

## 完整性与发布检查

```powershell
.venv/Scripts/python.exe scripts/verify_deployment_bundle.py
.venv/Scripts/python.exe scripts/release_preflight.py
```

首次启动之前可对完整性检查追加 `--fresh`，这会额外检查没有 `.env` 或运行数据库。启动后模型配置的状态字段会更新，普通检查允许该变化，但要求模型名称、修订号和相对路径保持准确。完整性清单用来检测损坏，不是学校业务签署或第三方发布签名。

发布盘点退出码2是当前预期结果：正式身份、政策审核、生产配置、HTTPS及微信真机未全部落实。不得通过删除启动阻断把本地试用称为正式服务。

## 已准备的迁移方式

模型配置使用 `models/qwen2_5_0_5b` 相对路径，模型首次加载后继续保留相对路径。BGE保持固定修订缓存目录。原件、标准化文本和索引均随部署包保留，并有逐文件SHA256清单；不依赖原机器的用户目录。

重建部署包时，先更新不含密钥的源码包，然后在原项目目录运行：

```powershell
.venv/Scripts/python.exe scripts/prepare_local_deployment.py --source-zip "../校院政策咨询Agent项目包.zip" --destination "../local-deployment-new" --archive "../校院政策咨询Agent本地部署包-new.zip"
```

输出目录和ZIP必须是新路径；脚本不覆盖已有部署副本。运行时只从本项目已缓存的固定模型复制，不下载新模型、不读取本机数据库、不自动上传任何文件。它会检查源码包文件哈希，并扫描导出文件中是否出现当前已配置的密钥值；密钥内容不会写到报告里。

## 云端接续与验收边界

当前已验证的依赖环境是Windows，Linux、Docker和具体云主机尚未安装验证。当前Windows锁文件含平台专用依赖，不能直接作为Linux部署已完成的证据。云资源落实后再按目标架构配置Linux依赖、持久化目录、反向代理与HTTPS，保持一个后端进程起步。

本轮隔离迁移验收记录位于交付目录的 `本地部署验收报告.json`，源码目录同时留有 `docs/verification/local_deployment.json`（均在实际运行完成后生成，独立于待测ZIP）。应分别记录：换目录后能否启动、BGE与Qwen是否真实离线加载、咨询是否有原文依据、附件哈希、学生权限拒绝、原目录是否仍可用。测试复用本机已安装依赖时必须明确记录，不能写成新机器安装通过。

包内的验证记录是打包时已有的历史记录。最终ZIP的验收报告独立交付，使用其中 `archive_sha256` 与交付ZIP比对；包内 `deployment-manifest.json` 校验部署文件，`docs/package_manifest.json` 描述输入源码包，两者用途不同。

当前没有注册云账号、领取云实例、购买资源或提交微信平台审核。本地准备完成后，后续免费资源领取、到期和付费升级的边界见 `免费试用与升级部署准备.md`。
