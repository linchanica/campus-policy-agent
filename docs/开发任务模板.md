# 开发交接与任务模板

每次改动记录任务编号、具体触发问题、修改文件、真实执行的检查与剩余限制。本地源码基线不代表已经过团队人工评审。

## 规则任务示例

T25：读取 data/normalized/p012.txt，定位双排名与班型例外。列出原文、已编码条件和仍需人工判断的条件；修复只比较一种排名的问题。增加能暴露错误的20%、30%与一项未达标用例。运行对应规则测试及固定评测，保留实际结果。不改变政策审核状态。

## 双端任务示例

T40：核对 contracts/openapi.json 的来源和材料字段，在共享学生端渲染出处与缺件状态。所有平台差异集中于 services/files.ts；运行 typecheck、build:h5、build:mp-weixin。构建通过后仍需分别人工检查浏览器和微信真机，不把未执行的操作写成通过。

## 更新任务示例

T58：先在独立目录接收新政策，记录原网页、取得时间、哈希、替代关系和业务审核人。提交差异与受影响用例。当前版本尚无完整在线审核发布管理，不能直接覆盖运行中的data目录并宣称已完成发布。详见运维操作文档。
