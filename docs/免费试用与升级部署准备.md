## 当前选择

不限定 Railway 或其他供应商。先核实腾讯云免费试用资格：官方页面目前列有个企同享的4核8GB轻量应用服务器、试用1个月、180GB系统盘，且标注每日限量。以本人登录后实际可领配置与0元订单为准；不存在已保证领取成功的额度。

候选配置采用Linux x86_64、单实例、单个后端进程，保持现有Qwen2.5-0.5B-Instruct与BGE模型。8GB内存是部署测试的起点，不是经过压测的容量承诺。若只能领取4GB内存，先测模型冷启动、并发、磁盘和内存峰值，不自动删模型或改成云端付费API。

来源：[腾讯云免费体验馆](https://cloud.tencent.com/act/pro/free)。页面也列有续费入口；具体试用实例能否原地升配、续费价格、超额流量处理方式，须在实际订单与控制台核实。

## 领取前的操作

1. 本人注册、登录并完成符合实际身份的实名认证；证件、验证码、密码不发到聊天里。
2. 查看是否有产品新用户资格及库存，核实配置、系统镜像、地域和期限。
3. 在创建前确认总价为0元，没有另行收费的数据盘、快照、带宽、数据库或安全产品。核实超额流量是否停用、是否另计费；未能排除新增费用时先停在订单核对。
4. 不开通自动付费续费，不勾选自动转付费或超额按量服务；需要充值、签订扣款授权或提交非零金额订单时由用户另行决定。
5. 实例创建后记录实际实例ID、到期日及费用规则；不把凭证写入资源台账或代码。当前未创建，因此到期日保留空值。

## 资源拿到后执行

1. 对目标Linux主机做环境检查。当前交付环境是Windows、Python3.13；Windows依赖锁含pywin32等平台包，不能直接照搬。需生成并验证Linux依赖清单。
2. 从不含密钥、学生会话、机器配置和模型缓存的源码包部署。初次试用使用隔离数据库与虚构测试资料，不直接上传当前本地数据库。若确需迁移历史数据，先核实迁移范围和接收环境。
3. 按固定修订准备本地模型、生成Linux路径的模型配置，校验政策原件和向量索引。不把Windows模型绝对路径当成云端可用路径。
4. 将数据库、发布快照、政策原件、索引和模型缓存放到持久化位置；当前架构先用一个后端进程，不直接多副本共享SQLite写入。
5. 先通过仅本机可达或受控连接验证健康检查、咨询、版本来源、附件、权限、备份恢复和内存峰值；尚未完成Linux适配或云端验收。
6. 正式对外服务前完成生产配置、准确HTTPS入口、小程序服务器域名及下载域名、真机验收、账号后台要求和业务审核。当前APP_ENV=production启动阻断保持有效，不能以development公开端口代替生产部署。

## 免费部署与正式发布的区别

免费算力可以先完成部署测试；不代表域名、认证和正式发布所需资源已经具备。当前没有域名和HTTPS服务，45份政策副本尚无学校正式业务审核。

腾讯云官方试用页要求，用轻量服务器办理备案时包月时长需达到3个月及以上，并有剩余有效期要求。因此只领取1个月试用不能直接视为已满足备案条件。若学校能够提供合规域名与运行资源，再按实际授权接入，不自行使用或占用学校域名。

云开发CloudBase是另一条路线，但不是当前FastAPI、SQLite、本地模型项目的直接替换。免费环境的功能、额度及发布后有效期均有限制，需按所选环境的实际规则核实，不承诺永久免费正式运行。来源：[CloudBase价格文档](https://cloud.tencent.com/document/product/876/75213)。

## 后续升级和迁移

1. 先确认预计访问量、当前内存峰值、响应时间和实际账单方案；用户确认费用后再续费或升级。
2. 同平台实例支持时可续费或升配；若免费实例受活动规格限制，则新建目标资源迁移。不能提前保证原地扩容。
3. 升级前建立一致数据库备份，并保存已登记的政策发布快照、原件哈希、规则卡、向量索引和代码版本。模型按固定修订恢复，密钥由服务端受控配置。
4. 目标环境验证咨询结果、旧引用、附件和身份权限后切换稳定HTTPS域名；旧环境保留可回退备份，再由责任人决定清理时间。
5. 若HTTPS域名保持不变，服务器迁移通常无需修改小程序的API地址；域名改变时需更新平台配置、重新构建并按平台要求更新版本。
6. 未决定续费时，在到期前导出备份并停止使用试用环境；不能把试用到期等同于数据仍被永久保留。实际时间以领取后记录为准。

## 只读发布盘点

项目目录下运行：

```powershell
.venv/Scripts/python.exe scripts/release_preflight.py
```

该命令不读取.env、不显示登录凭证，不登录云账号，不产生订单，不改变运行数据。输出只表示源码、基线资料、模型路径、数据库汇总和微信构建的可见状态；退出码2表示正式发布仍未就绪。即使传入候选HTTPS地址，语法通过也不代表证书、域名备案或服务可用性通过。

需要用户本人操作的下一步是云账号登录及实名认证；免费资源的资格、订单和到期规则核实后，再继续部署。当前不需要提供支付密码、银行卡信息、API Key或微信AppSecret。
